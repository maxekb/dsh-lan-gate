# dsh-lan-gate

Шлюз доступа к веб-GUI **DeepSeek Harness (DSH)** из локальной сети: обратный прокси, который
поднимается внутри процесса DSH и отдаёт интерфейс на `0.0.0.0:3088` — с одобрением устройств,
привязкой токена к cookie, ограничением частоты запросов и режимом телефонной раскладки.

Автор — MaxEkb77 ([github.com/maxekb](https://github.com/maxekb)).

English version: [README.en.md](./README.en.md). Плагин самодостаточный: без
подпроцессов, без внешних зависимостей, без телеметрии и любых исходящих запросов наружу.

## Что умеет

- **Обратный прокси** на `LAN_GATE_HOST:LAN_GATE_PORT` (по умолчанию `0.0.0.0:3088`) к
  локальному веб-серверу DSH.
- **Одобрение устройств**: первое обращение с нового адреса требует подтверждения на самой
  машине с DSH; одобрение живёт 90 дней, после чего устройство снова просит доступ.
- **Токен + привязка cookie**: одно одобрение привязывается к одному браузеру, токен
  используется однократно.
- **Ограничение частоты**: на IP и минуту (по умолчанию 120 запросов, при превышении — 429).
- **Режимы доступа**: `auto` / `phone` / `desktop`; телефонный режим подмешивает компактную
  раскладку интерфейса.
- **Админ-панель** внутри «Настройки → LAN Access» в самом DSH: список устройств, доверенные
  подсети, отклонение доступа.

## Требования

- DeepSeek Harness `>= 0.1.7-rc.2` (проверено на `0.2.0-rc.2`).
- Node.js `>= 20`.
- Плагин использует сервисы DSH `webServer` и `connection`; браузерной половины у него нет —
  панель администрирования отдаётся хост-частью.

## Установка

Как пакет-бандл (строка в композицию добавляется из `cordis.patch.yml` пакета):

```sh
dsh plugin --profile web add dsh-lan-gate
```

Или из каталога с исходниками:

```sh
dsh plugin --profile web add <путь-к-проекту>
```

После установки перезапустите DSH: строка композиции читается при старте процесса.

> **Важно.** Если профиль уже подключает шлюз по пути к файлу (строка `- id: lan-gate` с
> `name: ../../lan-gate/lan-gate.mjs`), **замените** эту строку, а не добавляйте вторую: два
> узла с одним `id` конфликтуют.

## Настройка

Переменные окружения:

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `LAN_GATE_HOST` | адрес прослушивания | `0.0.0.0` |
| `LAN_GATE_PORT` | порт шлюза | `3088` |
| `LAN_GATE_TOKENS_FILE` | файл со ссылками входа | `$DSH_HOME/lan-gate-tokens.md` |
| `DSH_HOME` | каталог состояния DSH | `~/.dsh` |

Файлы состояния:

- `$DSH_HOME/lan-gate-state.json` — решения по устройствам и список доверенных подсетей
  (меняются через админ-панель; каталог и файл создаются при первом запуске);
- `$DSH_HOME/lan-gate-tokens.md` — ссылка входа с одноразовым токеном текущего процесса.

Доверенные подсети по умолчанию — `192.168.1.` и `192.168.100.` (каноническая форма — CIDR,
например `192.168.1.0/24`); список хранится в файле состояния и правится в админ-панели.

## Безопасность — прочитать до включения

- Плагин открывает **полный интерфейс DSH** в локальной сети. Это доступ к агенту, файлам и
  инструментам вашей машины, а не «страница статуса».
- Защита строится на одобрении устройства, привязке cookie и лимите частоты. **Сужение
  доверенных подсетей — ваша ответственность**: не оставляйте подсети шире, чем нужно.
- Файл `lan-gate-tokens.md` содержит **действующую ссылку входа в открытом виде**. Держите
  каталог приватным и не публикуйте его содержимое.
- Не выставляйте порт шлюза напрямую в интернет. Для внешнего доступа ставьте перед ним
  терминатор TLS и/или VPN — сам шлюз рассчитан на локальную сеть.
- Телеметрии нет и данные наружу не уходят. Исходящие соединения в коде есть ровно два
  вида, и оба ведут на эту же машину: проксирование запроса к локальному веб-серверу DSH
  (http.request в sendUpstream, 
et.connect для WebSocket-апгрейда) и вызовы внутри
  отдаваемой админ-панели к собственным маршрутам шлюза (etch('/lan-gate/...')).

## Ограничения

- Состояние — один JSON-файл; одновременная правка из нескольких процессов не координируется.
- Один экземпляр шлюза на процесс DSH (повторная строка с тем же `id` — ошибка композиции).
- Телефонный режим влияет на раскладку интерфейса, а не на состав функций.
